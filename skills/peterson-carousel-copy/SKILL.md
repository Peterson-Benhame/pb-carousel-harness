# Copy do carrossel

Produza o conteúdo completo e pare antes do design. Esta skill não renderiza imagens.

## Preparação

Leia `../../shared/brand.json`, `../../shared/themes.json`, `../../shared/carousel.schema.json` e `../../shared/references/content-contract.md`. Confirme o objetivo do conteúdo quando ele não estiver claro: salvar, compartilhar, gerar discussão, estimular relatos ou converter para a mentoria pelo link da bio.

Use um dos modos de voz:

- `default`: direto, didático, prático e estratégico.
- `provocative`: somente quando solicitado; questione ideias, não ataque pessoas.
- `personal-story`: somente com fatos fornecidos por Peterson.

Para história pessoal, faça uma entrevista SAR com uma pergunta por vez: situação, ação, resultado, aprendizado e limites do que pode ser publicado. Continue até obter dados suficientes. Não complete lacunas por inferência.

Pesquise alegações atuais, dados, ferramentas, comandos e APIs em fontes primárias. Identifique inferências. Não invente histórias, citações, números, comandos ou referências.

## Roteiro

Escreva de 12 a 16 lâminas quando o tema sustentar essa extensão. Se ele não sustentar 12, proponha um recorte melhor ou solicite uma exceção explícita; não use repetição para preencher a contagem.

Estruture uma ideia central por lâmina:

1. `cover`: hook e promessa.
2. `context`: problema, contexto ou tensão.
3. `content`: desenvolvimento progressivo.
4. `summary`: síntese aplicável.
5. `cta`: uma única ação coerente.

Escolha apenas um CTA principal:

| Objetivo | CTA |
| --- | --- |
| Educativo | Salvar para consultar depois. |
| Útil para colegas | Compartilhar com alguém. |
| Provocativo | Comentar uma opinião fundamentada. |
| História pessoal | Compartilhar uma experiência relacionada. |
| Conversão coerente com mentoria | Acessar a mentoria pelo link da bio. |

Use hashtags específicas e moderadas. Escreva texto alternativo que explique o conteúdo e a lógica visual sem repetir toda a legenda.

## Entrega para revisão

Produza um JSON válido conforme o contrato compartilhado. Depois, apresente uma tabela legível com número, função, título, texto, posição visual e intenção de cada lâmina. Mostre também legenda, CTA, hashtags, texto alternativo e fontes.

Encerre exatamente com:

`AGUARDAR APROVAÇÃO DO TEXTO`

Não proponha conceitos visuais, gere imagens ou inicie a renderização até Peterson aprovar o conteúdo.
