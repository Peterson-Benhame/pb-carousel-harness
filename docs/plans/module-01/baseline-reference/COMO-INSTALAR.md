# Instalação no Windows

## Requisitos

- ChatGPT Desktop para Windows.
- Node.js 18 ou superior.

## Instalar

1. Extraia todo o conteúdo do ZIP.
2. Clique duas vezes em `instalar-plugin.cmd`.
3. Aguarde a instalação das dependências.
4. Feche completamente e abra novamente o ChatGPT Desktop.
5. Abra `Plugins` e selecione `Personal`.
6. Abra `Peterson Carousel Suite` e clique no botão `+`.
7. Inicie uma nova conversa no modo Work.
8. Digite `@peterson-carousel-suite` ou peça naturalmente um carrossel.

O instalador preserva outros plugins pessoais. Se o marketplace já existir, ele cria `marketplace.json.bak` antes de atualizá-lo.
